QA testing — noldan

Har bir dars kichik va tugallangan. Tartib bilan yuring: keyingi dars oldingisining ustiga quriladi.

Darslar

№DarsNima o'rganasiz
1 Dasturchi qaytarib yubormaydigan bug report Topilgan xatoni takrorlanadigan qilib yozish
2 Cheksiz variantdan to'rttasini tanlash Ekvivalentlik sinflari va chegara qiymatlari
3 Boshqa odam ham bajara oladigan test Test case yozish va hujjatlashtirish
4 Hisobot yuborildi — endi nima bo'ladi? Bug hayot sikli, retest va regression
5 Talab yo'q — nimadan boshlaysiz? Exploratory testing: charter, timebox, evristikalar
6 Ekranning orqasini ko'rish: DevTools Console va Network — hisobotga texnik dalil qo'shish
7 Talab qayerdan keladi User story, acceptance criteria, savol berish ko'nikmasi
8 Hisobot qayerda yashaydi: Jira Bug tracker: maydonlar, status, resolution, JQL
9 Vaqt oz, ish ko'p: test plan Qamrov, risk, kirish/chiqish mezonlari, vaqt bahosi
10 Sizning ishingiz qayerda boshlanadi Test darajalari, funksional va nofunksional turlar
11 Ekran aldashi mumkin: SQL Bazani tekshirish: SELECT, WHERE, JOIN, NULL
12 Tugmasiz test: API va Postman HTTP metodlari, JSON, Postman, API test holatlari
13 Ilova qurilmaning egasi emas Mobil testing: uzilishlar, ruxsatlar, tarmoq, qurilma matritsasi
14 Avtomatlashtirish: nima, qachon va qachon emas Foyda va xavflar, test piramidasi, qaror qabul qilish
15 Bilim bor — endi uni ko'rsatish kerak Portfolio, rezyume, suhbat savollari, sertifikat
16 Eshik yopiqmi yoki shunchaki yopiq ko'rinadimi? Xavfsizlik asoslari: OWASP Top 10, kirish nazorati, sessiya
17 Sichqonchasiz o'tib ko'ring Accessibility: POUR, to'qqiz tekshiruv, klaviatura sessiyasi
18 «Sekin» — bu bug report emas Core Web Vitals, o'lchash, yuk testi turlari
19 Birinchi avtomatlashtirilgan testingiz Playwright: o'rnatish, lokatorlar, tekshiruvlar
20 Faqat sizning kompyuteringizda ishlaydigan test — himoya emas CI/CD: workflow, artifact, qizil build tahlili
21 Vaqtingiz aslida qayerga ketadi Test muhitlari, test ma'lumoti, «iflos ma'lumot» kutubxonasi
22 Bizning tilimiz — tayyor test maydoni Lokalizatsiya: apostrof, ikki alifbo, format va tarjima
23 Ishingiz ko'rinmasa, u bajarilmagan hisoblanadi Test hisoboti, foydali va xavfli metrikalar
24 AI: kuchli yordamchi, yomon guvoh AI dan foydalanish va uni tekshirish qoidalari
25 Endi o'qish tugadi 30 kunlik amaliy reja — yakuniy dars

Darslar qanday bog'langan

1–3-darslar asosiy zanjir: nimani sinash (2) → qanday yozib qo'yish (3) → topilganini qanday yetkazish (1).

4–6-darslar shu zanjirni kengaytiradi: hisobot yuborilgandan keyin nima bo'ladi (4), talab bo'lmaganda qanday ish tutish (5) va dalilni qayerdan olish (6).

7–10-darslar jamoadagi ishga o'tadi: vazifa qayerdan keladi (7), ish qayerda yuritiladi (8), cheklangan vaqtni qanday taqsimlaysiz (9) va sizning ishingiz umumiy jarayonning qaysi qismi (10).

11–14-darslar texnik ko'nikmalar: ma'lumotni bazadan tekshirish (11), interfeyssiz API test qilish (12), mobil ilovaning o'ziga xos xatolari (13) va avtomatlashtirish qarori (14).

15-dars hammasini yig'adi: o'rgangan narsangizni portfolio, rezyume va suhbat javoblariga aylantiradi.

16–24-darslar ixtisoslashgan yo'nalishlar: xavfsizlik, accessibility, performance, avtomatlashtirish, CI, test ma'lumoti, lokalizatsiya, hisobot va AI. Ularni istalgan tartibda o'qish mumkin.

25-dars hammasini 30 kunlik jadvalga aylantiradi — kursning yakuniy darsi.

Amaliyotsiz o'qish — bekor ish

Har bir darsda amaliy topshiriq bor va uning eng qimmatli qismi — yozganingizni menga yuborib, qaytar aloqa olish. Darslarni birin-ketin o'qib chiqish ko'nikma bermaydi; birinchi darsdagi bug report ni haqiqatan yozib ko'rish beradi.

Men sizning o'qituvchingizman. Har bir darsda amaliy topshiriq bor va uning eng qimmatli qismi — qaytar aloqa. Yozganingizni menga yuboring: bug report, test case yoki test qiymatlari jadvali. Tekshirib, aynan nima yetishmayotganini aytaman.

Tushunmagan joy bo'lsa ham shunchaki so'rang — dars qaytadan tushuntiriladi yoki yangi misol qo'shiladi.
