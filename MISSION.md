# Missiya: QA Testing (noldan)

## Nima uchun

Asilbek QA tester sohasini **noldan** o'rganmoqchi. Maqsad — nazariyani bilish emas,
balki haqiqiy dasturni test qila oladigan, topgan xatosini dasturchi tushunadigan
qilib yeta oladigan va buni ish/portfolio darajasida ko'rsata oladigan tester bo'lish.

> **Tasdiqlanmagan faraz:** yakuniy maqsad — QA tester bo'lib **ishga joylashish**.
> Foydalanuvchi buni hali tasdiqlagani yo'q. Tasdiqlangach yoki o'zgargach, shu bo'lim
> yangilanadi va learning record yoziladi.

## Muvaffaqiyat qanday ko'rinadi

- Berilgan ilova (veb-sayt yoki mobil app) uchun mustaqil ravishda test rejasini tuza oladi
- Xato topganda, dasturchi qo'shimcha savol bermasdan takrorlay oladigan bug report yozadi
- Test case va checklist yozadi — nimani test qilish kerakligini o'zi aniqlaydi
- "Nega bu yerni test qilding?" degan savolga asosli javob beradi (test dizayn texnikalari)
- Amaliy portfolio: kamida bitta real ilovaga to'liq test hujjatlari to'plami

## Cheklovlar

- **Til: o'zbek.** Darslar, savollar va reference hujjatlar o'zbek tilida.
- **Noldan boshlash.** Oldingi QA tajribasi yo'q deb hisoblanadi.
- **Sodda va aniq.** Foydalanuvchi aniq talab qildi: darsliklar sodda va aniq bo'lsin.
  Uzun nazariy matnlar emas — kichik, tugallangan, amaliyotga ulangan darslar.
- Dasturlash darajasi hali noma'lum. Aniqlanmaguncha manual testingdan boramiz.

## Kurs holati

Kurs yozib tugatildi: **25 dars va 22 ta reference hujjat**.

- **1–15-darslar** — asosiy zanjir: xato topishdan ish topishgacha
- **16–24-darslar** — ixtisoslashgan yo'nalishlar: xavfsizlik, accessibility,
  performance, avtomatlashtirish (Playwright), CI/CD, test ma'lumoti,
  lokalizatsiya, hisobot va AI asboblari
- **25-dars** — hammasini 30 kunlik amaliy jadvalga aylantiradi

Dastlab qamrovdan tashqarida deb belgilangan mavzular (automation, CI/CD,
performance, security) keyinchalik kursga qo'shildi — poydevor qurilgandan
keyin, 14-darsdan boshlab.

ISTQB sertifikati maqsad emas, lekin uning sillabusi asosiy bilim manbai
sifatida ishlatilgan — shuning uchun tayyorgarlikning katta qismi
allaqachon bajarilgan.

## Hozircha qamrovdan tashqarida

- Chuqur avtomatlashtirish (Page Object Model, katta framework arxitekturasi)
- Yuk testi asboblarini amalda qo'llash (k6, JMeter)
- Mobil avtomatlashtirish (Appium)
