Tez qoida

4xx — «sen noto'g'ri so'rading». 5xx — «men buzildim». Ikkinchisi deyarli har doim haqiqiy bug, birinchisi esa kontekstga qarab.

Bug report uchun DevTools dan nima olinadi

  • Console: qizil xato matni — to'liq, qisqartirmasdan
  • Network: muvaffaqiyatsiz so'rovning metodi, manzili va statusi (masalan POST /api/orders → 500)
  • Response: server qaytargan xato matni
  • Skrinshot: DevTools ochiq holda — panel ham ko'rinsin
  • Vaqt: so'rov qancha davom etdi (sekinlik haqidagi hisobotlarda)

Chegara qayerda — muhim savol

Brauzerdagi tekshiruv (maxlength, required) chetlab o'tilishi mumkin. Agar server ham tekshirmasa — bu jiddiy nuqson. Shuning uchun chegara qiymatlarini sinaganda «bu chegara qayerda qo'yilgan?» deb so'rang.

Tushunmagan xato xabarini menga tashlang. Konsoldagi matnni nusxalab yuboring — sodda tilda tushuntiraman va bu qanday bugga ishora qilishini aytaman.
