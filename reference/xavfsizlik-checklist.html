Xavfsizlik tekshiruvi (tester uchun)

Maxsus asbobsiz bajariladigan tekshiruvlar. Har bir muhim oqim uchun shu ro'yxatdan yuring.

⚠ Chegara

Faqat o'zingiz ishlayotgan mahsulotda, ish vazifangiz doirasida yoki mashq uchun ochilgan demo saytlarda. O'z hisobingiz bilan.

Hech qachon: ruxsatsiz begona tizimni sinamang; boshqalarning ma'lumotini o'qimang yoki ko'chirmang; yuk berib ishdan chiqarishga urinmang; topilgan zaiflikni ommaga chiqarmang.

1. Kirish nazorati (A01)

  • Manzildagi id ni o'zgartirsam, boshqa odamning yozuvi ochiladimi? (IDOR)
  • Tizimga kirmagan holda ichki sahifa manzili ochiladimi?
  • Oddiy foydalanuvchi admin sahifasiga yeta oladimi?
  • Interfeys yashirgan amal API orqali to'g'ridan-to'g'ri bajariladimi?
  • So'rovdagi narx, miqdor yoki rolni o'zgartirsam qabul qilinadimi?
  • Boshqa foydalanuvchining havolasi menda ochiladimi?

Asosiy qoida

Interfeysda tugmani yashirish — himoya emas. Server har bir so'rovda ruxsatni qayta tekshirishi shart.

2. Sessiya va autentifikatsiya (A07)

  • Chiqishdan keyin eski manzil ochiladimi?
  • Chiqishdan keyin «orqaga» tugmasi ma'lumot ko'rsatadimi?
  • Chiqishdan keyin eski token bilan API so'rovi ishlaydimi?
  • Sessiya identifikatori manzilda ko'rinadimi?
  • Zaif parol qabul qilinadimi («12345678», «Password1»)?
  • Ketma-ket noto'g'ri urinishlar cheklanadimi?
  • Parolni tiklash havolasi eskiradi va bir marta ishlatiladimi?
  • Uzoq harakatsizlikdan keyin sessiya tugaydimi?
  • Parol o'zgartirilganda boshqa qurilmalardagi sessiyalar tugatiladimi?

3. Xato xabarlari (A10)

  • Xato xabarida texnik ma'lumot bormi (baza nomi, fayl yo'li, stack trace)?
  • «Email topilmadi» va «parol noto'g'ri» alohida aytiladimi? (aytilmasligi kerak)
  • Server xatosi (500) foydalanuvchiga to'g'ridan-to'g'ri ko'rsatiladimi?
  • Noto'g'ri ma'lumot yuborilganda ilova yiqilib qolmaydimi?

4. Ma'lumot uzatish va saqlash

  • Manzil https:// bilanmi? http:// ga o'tsa nima bo'ladi?
  • Javob body'sida parol, token yoki hash qaytmaydimi? (DevTools → Network)
  • Parol maydoni ekranda yashiriladimi?
  • Maxfiy sahifa brauzer keshida qolmaydimi?
  • Boshqa foydalanuvchining shaxsiy ma'lumoti javobda keraksiz qaytmaydimi?
