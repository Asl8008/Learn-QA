Playwright shpargalkasi

Test yozayotganda shu sahifani yoningizda saqlang. Barcha misollar ishga tushirilib tekshirilgan.

O'rnatish

npm init -y
npm i -D @playwright/test
npx playwright install chromium

Test skeleti

import { test, expect } from '@playwright/test';

test.beforeEach(async ({ page }) => {
  await page.goto('https://example.com/');
});

test('nima tekshirilayotgani', async ({ page }) => {
  await page.getByRole('button', { name: 'Login' }).click();
  await expect(page.getByText('Products')).toBeVisible();
});

Doirani toraytirish

Bir nechta element mos kelsa Playwright xato beradi. Yechim — avval konteynerni toping:

const mahsulot = page.locator('.inventory_item')
  .filter({ hasText: 'Sauce Labs Backpack' });
await mahsulot.getByRole('button', { name: 'Add to cart' }).click();

Ro'yxat, jadval va kartochkalar bilan ishlashning asosiy naqshi.

Harakatlar

.click()Bosish
.fill('matn')Maydonni to'ldirish
.clear()Maydonni tozalash
.check() / .uncheck() Katakcha
.selectOption('qiymat')Ro'yxatdan tanlash
.hover()Ustiga olib borish
.press('Enter')Klaviatura tugmasi
page.goto(url)Manzilga o'tish
page.goBack()Orqaga

Tekshiruvlar

Yaxshi test kodi

  • Bitta test — bitta tekshiruv
  • Testlar bir-biriga bog'liq emas, istalgan tartibda ishlaydi
  • Nom nimani tekshirayotganini aytadi
  • Lokatorlar foydalanuvchi ko'radigan narsaga tayanadi
  • Takroriy qadamlar beforeEach ichida
  • Qo'lda kutish yo'q
  • Yiqilganda xato sababni tushuntiradi

codegen — qoralama uchun

Yaratilgan kodni o'zgartirmasdan ishlatmang: u ko'pincha mo'rt CSS lokatorlarni tanlaydi. Tartib: codegen bilan qoralama oling, so'ng lokatorlarni tavsiya tartibi bo'yicha qayta yozing.
