NULL qoidasi

= NULL hech qachon ishlamaydi — faqat IS NULL. Va esda tuting: NULL, 0 va '' — uchta boshqa-boshqa holat. Uchalasini ham alohida tekshiring.

Testerning doimiy so'rovlari

-- Test yozuvim saqlandimi?
SELECT * FROM users WHERE email = 'test01@mail.uz';

-- Oxirgi yaratilgan yozuv
SELECT * FROM orders ORDER BY id DESC LIMIT 1;

-- Dublikat bormi?
SELECT email, COUNT(*) FROM users
GROUP BY email HAVING COUNT(*) > 1;

-- Majburiy maydon bo'sh qolganmi?
SELECT * FROM orders WHERE user_id IS NULL;

-- Nechta yozuv bor?
SELECT COUNT(*) FROM orders WHERE status = 'pending';

-- Ortiqcha bo'sh joy bilan saqlangan ismlar
SELECT * FROM users
WHERE full_name LIKE ' %' OR full_name LIKE '% ';

-- Ikki jadvalni birga ko'rish
SELECT o.id, o.total, u.email
FROM orders o
JOIN users u ON o.user_id = u.id
WHERE o.status = 'pending';

Bazani tekshirish odati

  • Yozuv umuman yaratildimi?
  • Har bir maydonga aynan kiritganingiz tushdimi?
  • Bo'sh joylar qirqilganmi (LIKE ' %')?
  • Uzun matn kesilib qolmadimi?
  • Sana va vaqt to'g'ri zonada saqlandimi?
  • Bog'langan jadvalda ham yozuv paydo bo'ldimi?
  • O'chirilganda haqiqatan o'chdimi yoki faqat belgilandimi?
