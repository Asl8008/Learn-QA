Jira shpargalkasi

Bug yaratayotganda shu hujjatni yoningizda saqlang. Maydonlar, statuslar, bog'lanish turlari va JQL — bir sahifada.

Bug yaratish tartibi

  • Issue type = Bug
  • Summary — bitta gap: qayerda + nima bo'ladi
  • Description — qadamlar, kutilgan natija, haqiqiy natija
  • Environment — brauzer, OS, qurilma, versiya
  • Priority — quyidagi shkala bo'yicha
  • Attachment — skrinshot yoki video; konsol xatosi bo'lsa u ham
  • Labels / Components — mahsulotning qaysi qismi
  • Link — tegishli story yoki oldingi bug

Foydali JQL so'rovlari

Mening ochiq hisobotlarim
reporter = currentUser() AND statusCategory != Done
Menga biriktirilgan ishlar
assignee = currentUser() ORDER BY priority DESC
Retest kutayotganlar
project = SWAG AND status = "In Test"
Muayyan qismdagi buglar
type = Bug AND labels = checkout
Oxirgi haftada yaratilganlar
created >= -7d ORDER BY created DESC

Har bir jamoada boshqacha

Jira juda moslashuvchan: statuslar, maydonlar va workflow admin tomonidan o'zgartiriladi. Yangi ishga kirganingizda birinchi kunlarda so'rang: «Bug qaysi statuslardan o'tadi? Severity qayerda yoziladi? Retest kim qiladi?» Bu savollar sizni professional ko'rsatadi.

Yaratgan bug'ingizni yuboring. Skrinshot ham bo'ladi. Men maydonlar to'g'ri to'ldirilganini va hisobot dasturchi uchun yetarli ekanini tekshiraman.
