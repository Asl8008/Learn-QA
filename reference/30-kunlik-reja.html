30 kunlik jadval

Kuniga 60–90 daqiqa. Bajarilganini belgilab boring — ko'rinadigan progress eng yaxshi motivatsiya.

1-hafta — poydevor (1–4-darslar)

  • 1-kun · saucedemo'da 45 daqiqa erkin yurish
  • 2-kun · 3 ta bug report
  • 3-kun · Ekvivalentlik va chegara jadvali
  • 4-kun · Jadvaldagi qiymatlarni sinash
  • 5-kun · 5 ta test case
  • 6-kun · Test case'larni boshqa odamga bajartirish
  • 7-kun · To'plamni yig'ish va yuborish

2-hafta — jarayon (5–9, 23-darslar)

  • 8-kun · Jira loyihasi, hisobotlarni ko'chirish
  • 9-kun · Exploratory sessiya (charter bilan)
  • 10-kun · DevTools ochiq sessiya
  • 11-kun · Story uchun savollar va acceptance criteria
  • 12-kun · 4 soatlik test plan
  • 13-kun · Rejani bajarish, chetlanishni yozish
  • 14-kun · Yakuniy hisobot va yuborish

3-hafta — texnik ko'nikmalar (10–13, 16, 17, 21, 22)

  • 15-kun · SQLBolt 1–6
  • 16-kun · SQLBolt 7–12 va o'z so'rovlaringiz
  • 17-kun · Postman bilan tanishuv
  • 18-kun · API uchun 12 test holati
  • 19-kun · Mobil sessiya (uzilishlar)
  • 20-kun · Klaviatura + accessibility tekshiruvi; xavfsizlik sessiyasi
  • 21-kun · «Iflos ma'lumot» kutubxonasi, apostrof tekshiruvi

4-hafta — avtomatlashtirish va portfolio (14, 15, 18–20)

  • 22-kun · Avtomatlashtirish qarori jadvali
  • 23-kun · Playwright o'rnatish, 2 test
  • 24-kun · 3 test o'zingiz
  • 25-kun · Test case'ni kodga aylantirish
  • 26-kun · GitHub + CI, qizil build tahlili
  • 27-kun · Performance o'lchovi va hisoboti
  • 28-kun · Portfolio yig'ish
  • 29-kun · Rezyume + ovozli mashq
  • 30-kun · 15 ta suhbat savoliga javob

30-kunda tayyor bo'lishi kerak

  • Jira loyihasi: 15–20 ta bug report
  • 10+ test case va bitta test plan
  • 2–3 ta sessiya varaqasi
  • SQL so'rovlari va API test holatlari
  • Mobil, accessibility, lokalizatsiya topilmalari
  • Playwright loyihasi va ishlaydigan CI
  • Portfolio havolasi va bir betlik rezyume
  • 15 ta suhbat savoliga yozilgan javob
